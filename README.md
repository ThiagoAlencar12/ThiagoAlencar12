## 🧑‍💻 About Me

I'm a **Senior Mobile Software Engineer** with over **6 years of experience in software development**, specializing in building scalable, reliable, and high-performance mobile applications for **iOS and Android**.

My core expertise lies in **React Native, TypeScript, and Expo**, with experience in native integrations using **Kotlin and Swift**, bridging the gap between cross-platform and native mobile development.

Throughout my career, I've contributed to large-scale digital products such as **Sem Parar** and **Pontomais / VR**, working on applications used by millions of people across Brazil.

My experience goes beyond building interfaces. I focus on mobile architecture, performance optimization, offline-first solutions, data synchronization, reusable design systems, and software quality.

I also have a background in frontend and backend development, allowing me to approach mobile engineering with a broader understanding of software ecosystems.

## 🏗️ Engineering Principles

I believe that good mobile engineering goes beyond delivering features.

My approach to software development focuses on:

- Building maintainable and scalable architectures.
- Keeping business logic independent from UI components.
- Designing applications for unreliable network conditions.
- Measuring performance before applying optimizations.
- Treating automated testing as part of the development process.
- Making technical decisions based on trade-offs rather than trends.
- Using AI as an engineering productivity tool without compromising code quality, security, or critical thinking.
